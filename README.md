# Prism - Social Media Prototype

## Présentation du projet
Prism est un prototype de plateforme sociale au design sombre, développé pour le projet Yowl. L'interface se concentre sur une identité visuelle forte utilisant des contrastes de noir et de violet.

## Structure du dépôt
L'organisation des fichiers respecte l'arborescence suivante :

* **mvp/** : Répertoire contenant le code source de 
l'application (HTML/CSS/JS).

* **docs/** : Dossier regroupant la documentation relative aux tests utilisateurs.

* **README.md** : Fichier de présentation et d'instructions générales.

* **test_protocol.md** : Contient une description brève des consignes transmises aux testeurs pour l'exploration du prototype (Profil, Messages, Reels).

* **feedback_summary.md** : Regroupe les notes consolidées de 3 à 5 testeurs. Ce document met en évidence les problèmes récurrents, les points de confusion ainsi que les opportunités d'amélioration identifiées lors des tests.

## Modules principaux

* **Profil** : Affichage des statistiques utilisateur et zone de biographie éditable.

* **Messagerie** : Interface de discussion.

* **Reels** : Flux vidéo vertical avec intégration des boutons d'interaction sociale.

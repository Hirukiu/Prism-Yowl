# Prism - MVP Source Code

## Structure du répertoire
Ce dossier contient les fichiers sources nécessaires au fonctionnement du prototype :

* **frontend/** : Fichiers sources de l'interface utilisateur (HTML, CSS, JS).

* **backend/** : Logique serveur et gestion des données.

* **Prism.sql** : Script de configuration de la base de données.

* **docker-compose.yml** : Fichier d'orchestration pour le déploiement des conteneurs.

## Documentation liée
Le développement de ce MVP s'appuie sur les tests utilisateurs documentés dans le dossier docs 

* **test_protocol.md** : Protocole et consignes de tests du prototype.

* **feedback_summary.md** : Synthèse des retours des testeurs.

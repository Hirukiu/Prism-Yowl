# Benchmark

## Social Media X:

### Structure: 3 colones

	Partie gauche: navigation (barre recherche, notification, follow...)
	Partie centrale: contenu (les postes) / pour vous
	Partie droite: découverte (News) / recommendation d'utilisateur/ top tendance / abonnement premium 

### Points Forts: 

	Navigation facile 
	IA intégrée (Grok)

### Points faibles:

	Colone de droite trop de pub
	Informations inutiles
 
## Instagram:

### Structure: 3 colones

	Partie gauche: navigation (accueil, barre recherche, découvrir...)
	Partie centrale: contenu (les postes) / pour vous 
	Partie droite: suggestion d'utilisateur / petite fenetre de messages pour communiqué

### Points forts:

	Navigation facile
	Accès au réel des personnes suivi facilement (juste au dessus du contenu)

### Points faibles:

	Trop de contenu sponsorisé qui gene le flux de contenu

## Facebook:

### Structure: 3 colones

	Partie gauche: navigation (ami, souvenir, enrengistrement...)
	Partie centrale: contenu (les postes, mini barre de navigation)
	Partie droite: création de groupe, discussion, notification...)

### Points forts:

	Navigation facile 
	IA intégrée

### Points faibles:

	Beaucoup de pub pas en lien avec l'interet des utilisateurs.
	Ajout de pleins de nouveauté comme Marketplace, boutique, evenement ( jeux ) ... L'envoi de message devient une action secondaire.

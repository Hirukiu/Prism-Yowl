Méthode MoSCoW (La plus simple)

Fonctionnalité:
    M (Must Have): 
        - Création de compte / Connexion --> Sans compte personne peut se connecter

        - Feed : contenu des gens --> Pour voir le contenu des autres

        - Poster du texte/photo --> Il faut le contenu avant les réels

        - Interface modulable   --> Base de notre site

    S (Should have): 
        - Messagerie privée  --> Vital pour un réseau social, mais on peut s'en passer pour le début

        - Format réels --> Dur a réaliser (stockage, vidéo, lecture fluide...)

    C (Could have): 
        - Interface Modulable Avancée --> Laisser l'utilisateur bouger chaque pixel

    W (Won't): 
        - Filtre vidéo (tiktok) --> Trop complexe pour le temps donné

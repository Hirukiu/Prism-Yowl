# description MVP Scope:

## 1. main user flow:

    1. **Lancement de l'application :** L'utilisateur arrive sur le Flux principal et voit l'interface par défaut.

    2. Scroll : L'utilisateur fait défiler les publications.

    3. Personnalisation: L'utilisateur clique sur le bouton pour changer de module.

    4. Modification : La mise en page du site change selon la personnalisation de l'utilisateur.

    5. Action: L'utilisateur rédige un message et l'envoie dans le flux.

## 2. Essential Screens:

    1. structure: Une page principale, barre latérale a gauche avec les différents modules, le flux de contenu au centre , avec barre horizontale (parametre, profile...)

    2. Register/Sign In: Une page pour crée un compte et se connecter.

## 3. Minimal Features: 

    1. Lecture : Affichage d'une liste de posts
    2. Ecriture : Ajouter des commentaires
    3. Modification : Modification des modules

## 4. What is explicitly excluded:

    1. Pas d'IA

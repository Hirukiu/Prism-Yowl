# Documentation de la Priorisation 

Ce document définit le périmètre de développement pour la phase suivante du projet en s'appuyant sur des méthodes de priorisation rigoureuses pour identifier le Produit Minimum Viable (MVP).

## Documents de référence

### 1. Matrice de Priorisation 
Ce document présente la méthode de sélection des fonctionnalités (MoSCoW, RICE ou autre) utilisée pour arbitrer les choix techniques.
* **Méthodologie** : Justification des critères retenus pour classer les fonctionnalités selon leur impact utilisateur et leur coût de développement.
* **Résultats** : Liste hiérarchisée des éléments à intégrer en priorité.

### 2. Définition du MVP
Ce fichier contient une description précise du périmètre retenu pour la première version fonctionnelle développée en Phase 2.

* **Flux utilisateur principal** : Parcours critique que l'utilisateur doit pouvoir accomplir sans interruption.
* **Écrans essentiels** : Liste des interfaces indispensables au fonctionnement du flux principal.
* **Fonctionnalités minimales** : Ensemble des capacités techniques strictement nécessaires pour répondre au besoin utilisateur.
* **Exclusions explicites** : Inventaire des fonctionnalités et écrans reportés à des versions ultérieures pour garantir la tenue des délais.

**Note :** Ce travail de priorisation sert de base contractuelle et technique pour le lancement effectif du développement.

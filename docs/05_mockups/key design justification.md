Pour le design du site nous avons choisi d'aller vers un UI (user interface) de couleur sombre avec des touches de violet. Egalement le UX (user experience) est orienté vers la customisation pour que les utilisateur puisse choisir les fonctionnalité de l'application qui les intéresse le plus grâce au modules qui sont interchanchable. Les utilisateur peuvent aussi profiter d'un HUB de communauté ou d'autre module peuvent être créer et partager. Pour le prototype nous avons décidé de présenter les modules classiques: messages, reel/short et vidéo en plus des pages de paramètre et de profile.

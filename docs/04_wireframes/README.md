# Documentation des Wireframes

Ce document répertorie et décrit les maquettes fonctionnelles (basse fidélité) réalisées pour visualiser l'architecture de l'application et l'agencement des éléments d'interface.

## Inventaire des écrans

### 1. Authentification

Cet écran présente les formulaires d'entrée pour l'utilisateur.

	Module Register (Inscription) : Formulaire demandant le Prénom (First name), Nom (Last name), Email et Mot de passe.
	Module Login (Connexion) : Formulaire simplifié demandant uniquement l'Email et le Mot de passe.

### 2. Interface Modulaire & Accueil (`PARAMETRE + DRAG N DROP.png`)

Cet écran illustre le concept central de personnalisation et l'architecture de la page d'accueil.

	Zone de contenu central : Emplacements pour le "Menu Principal", le "Feed" (Fil d'actualité) et les "Notifications".
	Bibliothèque de modules : Une grille en bas d'écran proposant divers modules activables : "Forum", "Blogging", "Career Network", "Live/En Direct", "Trade".
	Navigation : Barre latérale gauche avec des emplacements "Exemple" et barre supérieure standard (Paramètre, Rechercher).

### 3. Visionneuse de Contenu

Maquette dédiée à la consommation de vidéos courtes ou de médias immersifs.

	Affichage : Zone de lecture principale occupée par un large bloc noir (placeholder vidéo).
	Navigation : Menu supérieur (Paramètre, Notifications, Rechercher) et barre de navigation inférieure active sur l'onglet "Short/Reel".

### 4. Messagerie

Interface dédiée aux échanges privés entre utilisateurs.

	Liste de contacts (Gauche) : Colonne listant les correspondants.
	Zone de conversation (Droite) : Espace de chat affichant les bulles de messages entrants et sortants.

### 5. Profil Utilisateur

Page personnelle de l'utilisateur regroupant ses informations et réglages.

	Identité : Large avatar circulaire avec option d'édition ("Edit").
	Champs de données : Liste modifiable contenant le Nom d'utilisateur, Mot de passe, Nom de famille, Prénom.

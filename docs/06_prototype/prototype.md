## Description des interactions supportées

Le prototype est cliquable et simule les fonctionnalités principales de l'application pour démontrer l'expérience cible :

	Navigation Globale : Exploration fluide entre les différentes pages et sections de l'application.

	Gestion des Modules : Interaction permettant de retirer et d'ajouter un module existant.
	
	Messagerie : Simulation de l'envoi d'un message via l'interface de chat/communication.

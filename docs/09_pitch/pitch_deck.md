## Prism Project

# Problème
Les réseaux sociaux actuels sont soit trop généralistes, soit trop centrés sur un type d’utilisateur précis. De ce fait, les utilisateurs doivent télécharger plusieurs réseaux sociaux différents pour faire ce qu’ils veulent, et se retrouvent aussi à subir beaucoup de contenu inutile.

# Target Users
- Les utilisateurs de différent réseaux sociaux regroupé dans un seul et unique réseau social: Prism
- Utilisateur de réseaux social comme Instagram, YouTube, Twitch, Reddit, X (Twitter), Snapchat, etc.

# Concept
Une website application customisable dans laquelle les utilisateurs peuvent utiliser des modules pour rendre le réseau social le plus intéressant pour eux.

# UX (User Experience) Walkthrough
- Modules
- Mix de différentes fonctionnalités

# MVP Scope
- Accès a un espace utilisateur
- Affichage d'un flux de contenu modulable
- ajout/suppression de modules
- réorganisation visuelle des modules

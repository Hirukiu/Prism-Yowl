# Documentation Feedback

Ce document compile les protocoles de test et les conclusions tirées des sessions d'essais réalisées sur le prototype interactif.

## Documents de référence

### 1. Protocole de Test 
Ce fichier décrit les consignes et les scénarios de test soumis aux utilisateurs.
* **Objectif** : Vérifier l'ergonomie des modules et la fluidité du parcours utilisateur.
* **Tâches demandées** : 
    * Création d'un compte et connexion.
    * Personnalisation de l'accueil via la bibliothèque de modules (Drag n Drop).
    * Envoi d'un message privé et modification du profil.

### 2. Synthèse des Retours 
Ce document regroupe les notes consolidées issues de 3 à 5 testeurs.

* **Points de friction identifiés** : Recensement des problèmes récurrents rencontrés lors de la manipulation du prototype (ex: confusion sur certains boutons, latence perçue).
* **Confusions majeures** : Liste des éléments d'interface ayant nécessité une explication supplémentaire.
* **Opportunités d'amélioration** : Suggestions des testeurs pour optimiser l'expérience utilisateur et nouvelles idées de fonctionnalités.



**Note :** Les retours collectés servent de base pour les derniers ajustements avant le lancement du développement technique.
